# banking-atlas · 银行系统图鉴

一个学习银行 IT 的交互空间：把一家银行的系统全貌摊开来讲——从渠道、核心系统到监管报送与跨境清算，中美对照，全部内容可点开深读，并带学习进度标记。

## 内容

- **全景图**：七层 45 个可点模块（渠道 → 接入前置 → 业务中台 → 核心 → 外围 → 外部连接 → 基础设施）
- **核心系统全貌**：核心内部六层 19 个模块、一笔交易的八步旅程、四本账与勾稽关系、大机核心 vs 分布式核心对照
- **业务篇**（15 篇）：存款、贷款、支付清算、银行卡、中间业务、风险合规、数字人民币、监管报送、CIPS 跨境、票据、资金司库、财务与管理会计、数据治理、资产托管、国际结算与贸易金融
- **技术篇**（7 篇）：架构演进、日切与轧账、联机与批量、分布式一致性、容灾双活、性能容量、信创与国产化替代
- **业务全链路**：6 个可播放的动画场景（跨行转账、刷卡消费、贷款放款、工资代发、ATM 取现、数字人民币付款），逐步讲解流经系统、账务分录与失败处理
- **厂商与案例**：中美两组厂商卡与银行案例；**术语表** 53 条（白话 + 专业双解释）

地域口径：国外只做美国；中美对照不设总冠军——产品形态美国领先，分布式改造规模中国领先。

## 技术

- 前端：React 19 + TypeScript + Tailwind CSS 4（`client/`）
- 服务端：TypeScript actions + Drizzle ORM / SQLite（`server/`、`drizzle/`），服务端只存学习进度标记（已学 / 收藏）
- 内容：全部讲义内容在 `client/src/content.ts` 与 `client/src/core.ts`，业务全链路场景在 `client/src/journeys.ts`
- 构建：Bun（见 `package.json` 的 scripts）
